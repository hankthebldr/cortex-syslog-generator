## Integration with Cortex XSIAM

### Field Mappings

| Zscaler Field | XSIAM XDM Field | Description |
|---------------|-----------------|-------------|
| `suser` / `usrName` | `xdm.source.user.username` | User performing the action |
| `src` | `xdm.source.ipv4` | Source IP address |
| `dst` | `xdm.target.ipv4` | Destination IP address |
| `spt` / `dstPort` | `xdm.source.port` / `xdm.target.port` | Network ports |
| `act` / `ConnectionStatus` | `xdm.event.outcome` | Action outcome |
| `cat` | `xdm.event.type` | Event category |
| `devTime` | `xdm.event.timestamp` | Event timestamp |

### Transport Configuration

#### Syslog (Default)
```bash
# Local syslog receiver
dest_ip: "127.0.0.1"
enable_syslog: true

# Cortex Broker VM
dest_ip: "broker-vm-ip"
dest_port: 514
```

#### XSIAM HTTP API
```bash
export XSIAM_HTTP_ENDPOINT="https://api-yourtenant/logs/v1/xsiam"
export XSIAM_API_KEY="${XSIAM_API_KEY}"
enable_xsiam_http: true
```

#### Generic Webhook
```bash
export WEBHOOK_ENDPOINT="https://your-endpoint/webhook"
export WEBHOOK_TOKEN="${WEBHOOK_TOKEN}"
enable_webhook: true
```

## Usage Examples

### Web UI Generation
1. Start the generator: `make run`
2. Navigate to `http://localhost:5001`
3. Select Zscaler products:
   - Web Proxy (CEF)
   - NSS Firewall (CEF)
   - ZPA User Activity (LEEF)
   - ZPA User Status (LEEF)
   - ZPA Connector (LEEF)

4. Configure transport settings
5. Generate authentic logs

## Log Format Compliance

- **CEF Compliance**: NSS Web and Firewall logs follow CEF v0.1 standard
- **LEEF Compliance**: ZPA logs follow LEEF 1.0 format specification
- **Field Authenticity**: All fields match production Zscaler deployments
- **Timestamp Formats**: Multiple formats supported (ISO8601, epoch, syslog)
- **Character Encoding**: UTF-8 compliant for international deployments

These log formats have been validated against production Zscaler deployments and are designed for seamless integration with Cortex XSIAM's data ingestion and parsing capabilities.
